# AprilTag Generation & Camera Pose Estimation — Zoo 3D Reconstruction

Pipeline for printing AprilTag fiducial markers, resizing camera images, detecting tags,
and estimating camera poses in COLMAP format for 3D reconstruction.

---

## File Overview

| File | Purpose |
|---|---|
| `generate_apriltags.py` | Generate and tile all 35 tags (IDs 0–34) onto A4 print sheets |
| `tag_dict.py` | Shared tag bit codes and custom ArUco dictionary builder |
| `resize_images.py` | Resize camera RAW JPEGs to a smaller working resolution |
| `estimate_camera_pose.py` | Detect tags in images and output COLMAP camera poses |
| `visualize_apriltags.py` | Detect tags and save annotated images (neon-green outlines) |
| `apriltag_output/tag_configs.csv` | Tag ID → physical size in metres |
| `classroom_data/camera_info.md` | Canon EOS 5D Mark IV intrinsics and capture notes |

---

## Tag Sizes & Print Specs

All tiles are A4 portrait (210 × 297 mm) at 300 DPI.
Print at **100% / actual size** — do NOT use "fit to page".

| Tag IDs | Physical size (mm) | Physical size (m) | Grid | Pages per tag |
|---|---|---|---|---|
| 0–9, 15–34 | 209.97 × 209.97 | 0.20997 | 1×1 | 1 |
| 10–13 | 419.95 × 419.95 | 0.41995 | 2×2 | 4 |
| 14 | 839.89 × 839.89 | 0.83989 | 4×4 | 16 |

### One generator, one shared dictionary

All 35 tags are generated by `generate_apriltags.py` using OpenCV's official
`DICT_APRILTAG_36h11` bit patterns. All are detectable via the custom ArUco
dictionary in `tag_dict.py`. The standard `pupil_apriltags` / apriltag3 library
**cannot detect tags 0–14** (different spiral encoding used during printing).

## Assembly Instructions

### 1×1 (IDs 0–9, 15–34)
Single page. No assembly needed.

### 2×2 (IDs 10–13)
4 pages per tag. Arrange:
```
r0c0 | r0c1
-----+-----
r1c0 | r1c1
```
- **Vertical seams**: 10 mm content overlap — align using crosshair marks in margins.
- **Horizontal seams**: butt edge-to-edge — fold the right edge of the left page behind and tape. Use grey tick marks in margins to confirm alignment.

### 4×4 (ID 14)
16 pages. Assemble row by row following the same seam rules.

## Step 1 — Resize Images

`resize_images.py` downscales the Canon EOS 5D Mark IV RAW JPEGs (6720×4480) to a
smaller working resolution for downstream pipelines. EXIF metadata is preserved so
intrinsics can still be computed per image.

```bash
uv run resize_images.py                          # uses defaults
uv run resize_images.py -i raw/ -o resized/ -l 1000
```

| Argument | Default | Description |
|---|---|---|
| `-i / --input` | `classroom_data/raw/` | Input directory of JPEGs |
| `-o / --output` | `classroom_data/resized/` | Output directory |
| `-l / --long-edge` | `1000` | Target long-edge size in pixels |
| `-q / --quality` | `95` | JPEG output quality (0–100) |

**Note:** Run tag detection on the **raw full-resolution images**, not the resized ones.
Background tags that are ~150px wide at native 6720px shrink to ~20px at 1000px —
below the reliable decode threshold.

## Step 2 — Estimate Camera Poses

`estimate_camera_pose.py` detects tags and outputs poses in COLMAP's
World-to-Camera (W2C) format (X-right, Y-down, Z-forward).

```bash
uv run estimate_camera_pose.py \
  --images classroom_data/raw/ \
  --output classroom_data/output \
  --vis-dir classroom_data/vis/
```

| Argument | Default | Description |
|---|---|---|
| `--images` | *(required)* | Folder of input images |
| `--config` | `apriltag_output/tag_configs.csv` | Tag size config |
| `--output` | `poses.txt` | COLMAP images.txt output |
| `--vis-dir` | *(disabled)* | Save annotated visualisation images |
| `--exts` | `jpg jpeg png` | File extensions to process |

### How detection works

1. **Custom dictionary** — built from `tag_dict.py` to match the exact bit encoding
   of all 35 printed tags (IDs 0–34). Using the standard apriltag3 library failed
   to detect tags 0–14.

2. **Full-image pass** — runs the detector on the entire image.

3. **Tiled pass** — splits the image into a 2×2 grid with 20% overlap and runs the
   detector on each tile. Corner coordinates are mapped back to full-image space.
   This recovers small/distant background tags that are too few pixels wide to decode
   in the full image.

4. **Merge** — detections from both passes are deduplicated by tag ID, keeping the
   detection with the largest pixel area (most pixels = best pose accuracy).

### Camera intrinsics

Intrinsics are computed **per image** from EXIF focal length. No hardcoded K matrix.
The Canon EOS 5D Mark IV sensor pixel density (from EXIF focal plane resolution) is
scaled to whatever resolution the input image is.

This dataset was shot at two focal lengths — 24mm (20 images) and 31mm (1 image,
8Y0A8436.JPG) — so per-image intrinsics are required.

Distortion coefficients are currently zero (no lens calibration performed). See
`classroom_data/camera_info.md` for full intrinsics documentation.

### Output format

One line per image with at least one detected tag:

```
IMAGE_ID QW QX QY QZ TX TY TZ CAMERA_ID NAME
```

When multiple tags are visible in one frame, the pose is averaged across all detections
(translation averaged directly; rotation averaged via quaternion mean).

### Visualisation axes

Pass `--vis-dir` to save annotated images. Each detected tag gets three arrows drawn
from its center:

| Color | Axis | Direction |
|---|---|---|
| Red | X | Right along the tag face |
| Green | Y | Down along the tag face |
| Blue | Z | Out of the tag face toward the camera |

If the axes look physically correct for the angle you photographed the tag, solvePnP
got a good result. Badly oriented axes indicate a failed or noisy pose estimate.

## Step 3 — Visualize (optional)

`visualize_apriltags.py` is a lighter-weight detection viewer that draws neon-green
outlines and ID labels without running solvePnP. Useful for quickly checking which
tags are visible in an image.

```bash
uv run visualize_apriltags.py --images classroom_data/raw/ --output-dir classroom_data/vis/
```

## Known Limitations

- **Tags 0–14 use a custom spiral encoding** that only `tag_dict.py`'s custom dictionary
  can decode. The standard apriltag3 / pupil_apriltags library ignores them entirely.
- **Distortion is uncalibrated** — `dist = zeros`. The Canon EF 24-105mm f/4L IS II USM
  has measurable barrel distortion, especially at 24mm. Run `cv2.calibrateCamera()` with
  a checkerboard for better pose accuracy.
- **Poses are not in a unified world frame** — each pose is relative to the tag(s) visible
  in that image. To use in COLMAP, tag world positions must be known, or poses used as
  initialisation hints for SfM.
